# Indonesian Hoax News Detection

A web-based application for detecting potential hoax news in Indonesian text using Transformer-based language models, machine learning, Large Language Models (LLMs), and domain credibility analysis.

## Overview

The rapid spread of information through digital media makes it increasingly difficult to distinguish factual information from hoax news. **Indonesian Hoax News Detection** is developed as a multi-layer detection system that analyzes Indonesian news articles from different perspectives.

The application combines:

* **IndoBERT** for semantic text representation
* **Machine Learning classifiers** for text classification
* **GPT-3.5 Turbo** for additional language and reasoning analysis
* **Domain credibility analysis** using website reputation indicators
* **Streamlit** as the web application interface

The system is designed to provide an additional layer of verification rather than replace professional fact-checking.

## Features

* Indonesian news text analysis
* Text preprocessing and normalization
* Transformer-based semantic representation using IndoBERT
* Hoax and factual news classification
* Machine learning model comparison
* GPT-based analysis and explanation
* Domain credibility analysis
* Final detection result with confidence information
* Interactive web interface using Streamlit

## Machine Learning Models

The system evaluates several classification algorithms using semantic embeddings generated by IndoBERT:

| Model         | Description                             |
| ------------- | --------------------------------------- |
| SVM           | Support Vector Machine classifier       |
| Random Forest | Ensemble-based classification algorithm |
| Naive Bayes   | Probabilistic classification algorithm  |

The models use balanced class weighting to help handle the classification task between factual and hoax news.

## Research Dataset

The research dataset contains **5,040 Indonesian news articles**, consisting of:

| Label     |    Amount |
| --------- | --------: |
| Factual   |     2,520 |
| Hoax      |     2,520 |
| **Total** | **5,040** |

The dataset was collected from several Indonesian information sources and processed through cleaning, normalization, deduplication, and leakage removal procedures.

### Dataset Sources

* Kompas
* Detik
* Komdigi
* TurnBackHoax

The dataset is used for research and model evaluation purposes.

## Model Configuration

The Transformer component uses:

**Model:** `indobenchmark/indobert-base-p1`

Configuration:

* Hidden size: 768
* Transformer layers: 12
* Attention heads: 12
* Maximum sequence length: 512
* Semantic representation: 768-dimensional embedding

The `[CLS]` representation is used as the semantic representation of the input text.

## Research Results

Among the evaluated machine learning models, the **linear-kernel SVM** achieved the best classification performance.

| Metric            |     Result |
| ----------------- | ---------: |
| Accuracy          | **99.80%** |
| Weighted F1-Score | **0.9980** |
| Hoax Recall       |   **100%** |

These results represent the evaluation performed on the research dataset and should not be interpreted as a guarantee that every real-world news article can be correctly classified.

## Installation

### 1. Clone the Repository

```bash
git clone https://github.com/feriyanwyn/Indonesian-Hoax-News-Detection.git
```

### 2. Enter the Project Directory

```bash

```

### 3. Create a Virtual Environment



## Limitations

The detection result should be treated as an analytical indication rather than absolute proof that a news article is factual or hoax.

Several factors may affect the result, including:

* Ambiguous or incomplete information
* Rapidly changing news
* Satirical or opinion-based content
* Limited contextual information
* Changes in website credibility
* Model limitations and classification errors
* Quality and distribution of the training dataset

Users should verify important information using trusted sources and professional fact-checking organizations.
